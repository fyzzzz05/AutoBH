# AutoBH 0.1.5

- 新增阳光打卡：学期/本周/今日次数、分页运动记录、手动填写运动信息并上传照片提交。
- 可复用已绑定的上课或博雅密码，后台独立进行只读同步，不额外提交运动记录。
- 增加提交前核对、持久化重复提交保护及超时结果提示，刷新失败保留原缓存。
- 四项功能适配固定右侧面板与小窗口，详情弹窗独立滚动。
- 阳光协议参考 BUAASubnet/UBAA，MIT 版权声明随 App 分发。
- 新增“一键四连”：四段时间可按天错开并逐条编辑，提交前核对；查询本周次数后只补至 4 次，异常暂停，成功记录不重复提交。
- 顶部仅显示四个项目名称与后台状态灯，具体状态可悬停查看；未分组时隐藏分组标签。
- 更换 AutoBH 品牌图标：深青色圆角底、几何 A 与薄荷色勾形；同步 macOS Dock 和网页图标。
